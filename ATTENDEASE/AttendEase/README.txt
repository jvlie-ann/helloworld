ATTENDEASE (front-end only, no backend)
main/        no login. Open index.html (or attendease-all-in-one.html).
with-login/  log in / sign up first, then the same app.
Files in each folder: index.html, style.css, script.js, data.js (data rules), sample-data.js, assets/, tests/tests.js, attendease-all-in-one.html
Run the tests:  node tests/tests.js   (needs Node.js)
Data is saved in this browser; Settings > Download backup keeps a copy.
